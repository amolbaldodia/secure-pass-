# SecurePass 🔐
A Password Strength Checker built using HTML, CSS and JavaScript.

## Features
- Minimum 8 characters validation
- Uppercase and lowercase validation
- Number validation
- Special character validation
- Show/Hide password functionality

## Technologies Used
- HTML
- CSS
- JavaScript

## About
This project was created to practise frontend development and understand how HTML, CSS and JavaScript work together.# secure-pass-
